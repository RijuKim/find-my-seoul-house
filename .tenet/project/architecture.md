# Project Architecture

React 19 + Vite 7 + Tailwind 4 + shadcn/ui mobile web; pure budget/filter/interpretation functions and separate sample/live transaction and platform-location adapters. Express + tRPC 11 backend; Vitest 2; pnpm 10. Dual runtime: local Express dev/prod plus Vercel serverless via `api/trpc/[...trpc].js` esbuild bundle (generated by `scripts/build-api.mjs`, MUST be committed). Trade types: sale + jeonse. No database or financial-input persistence; exact coordinates transient; API keys server-only. Browser coordinates need a separate administrative resolver. Workers use Tenet/OpenCode ollama/deepseek-v4.1-flash (0731 retired 2026-09-25); host authors planning and design.
