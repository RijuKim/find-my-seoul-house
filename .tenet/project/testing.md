# Project Testing

Require strict typecheck, production build, deterministic pure-function tests with independent numeric expectations, and browser exploration. Vitest is the test framework. Browser acceptance is scripted via Playwright-MCP-callable modules under `tests/acceptance/` (run through browser_run_code_unsafe). Gates: `pnpm check`, `pnpm test`, `pnpm build`, `node scripts/build-api.mjs`. Cover zero income/rate, borrowing ceiling, fees, record filtering, unknown attributes, reset and errors. Playwright Layer 2 required at 360px/1280px. Every Tenet implementation has independent eval. No live API success claim without actual response evidence.
