# Project Overview

부둥부둥 helps Korean housing explorers understand available cash and income in terms of region, space and monthly burden using historical transactions. No active listings or underwriting promises. Brownfield web app, fully implemented and deployed at https://budungbudung.vercel.app (GitHub RijuKim/find-my-seoul-house, main). Mobile web without login. Live features: budget explorer (cash + income), deterministic interpretation layer, Kakao map, location signals, 3-item comparison, housing-type filters (전체/아파트/빌라·다세대) with apartment-scale filters, and trade type 매매/전세.
