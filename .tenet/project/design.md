# Project Design

Warm Korean mobile-first UI: cream background, dark green accents, clear amounts. Interpretation before building name; evidence close to claim; optional detail reveals assumptions. No budget shaming or house status ranking. Data-source + check-time provenance (국토부/K-apt/MOLIT); large touch targets (44px), keyboard focus, semantic labels and dialogs. shadcn/ui components live under `client/src/components/ui/` (edited only via the shadcn CLI); design tokens/palette live in `client/src/index.css`.
